# «Небосвод» — сайт прогноза погоды

Веб-приложение на **Python + Flask + SQLite**: прогноз погоды по городам, анимированный интерфейс и панель администратора для работы с базой данных.

## Запуск (Windows)

1. Установите **Python 3.10 или новее** (https://www.python.org/downloads/), при установке отметьте «Add python.exe to PATH».
2. Распакуйте папку проекта и дважды щёлкните **`run.bat`**.
3. Браузер откроется сам: http://127.0.0.1:5000

Интернет и `pip install` **не нужны** — Flask и его зависимости уже лежат в папке `vendor`.
Остановить сервер — закрыть окно консоли или нажать `Ctrl+C`.

Запуск вручную: `python app.py` (на Linux/macOS — `python3 app.py`).

## Вход в панель администратора

http://127.0.0.1:5000/admin — логин **admin**, пароль **admin123** (пароль можно сменить в разделе «Администраторы»).

## Вкладки сайта

| Вкладка | Что есть |
|---|---|
| **Сейчас** | Текущая погода выбранного города, влажность, ветер, давление, ближайшие 5 дней. Город меняется без перезагрузки страницы. |
| **Прогноз** | Прогноз на 7 дней и интерактивный график температуры и осадков. |
| **Города** | Все города с погодой, поиск и сортировка. |
| **Обратная связь** | Форма, сообщения сохраняются в БД; сведения о проекте. |
| **Админ** | Панель администратора (см. ниже). |

## Панель администратора

- **Обзор** — статистика, крайние температуры, новые сообщения, последние действия.
- **Города** — добавление (с поиском координат), изменение, скрытие, удаление.
- **Текущая погода** — ручное редактирование показаний для любого города.
- **Прогнозы** — добавление / изменение / удаление дней прогноза.
- **Сообщения** — сообщения посетителей (прочитано / удалить).
- **База данных** — структура таблиц, SQL-консоль (только чтение), скачивание резервной копии `.db`.
- **Администраторы** — добавление и удаление учётных записей, смена пароля.
- **Журнал** — история всех действий администраторов.
- Кнопка **«Обновить погоду из интернета»** загружает реальные данные из бесплатного API Open-Meteo. Без интернета сайт работает на данных из базы.

## База данных

Файл `weather.db` создаётся автоматически при первом запуске и наполняется демо-данными (9 городов, прогноз на 7 дней). Чтобы начать с чистой базы — удалите `weather.db`.

| Таблица | Назначение |
|---|---|
| `users` | администраторы (пароли — в виде хеша) |
| `cities` | города и координаты |
| `current_weather` | текущая погода (1 запись на город) |
| `forecasts` | прогноз по дням |
| `feedback` | сообщения посетителей |
| `action_log` | журнал действий администраторов |

## Анимации

Небо меняется под погоду (плавная смена градиента, дождь, снег, туман, облака, молнии, звёзды ночью — canvas), анимированные SVG-иконки погоды, плавный индикатор вкладок, переходы между страницами, появление блоков при прокрутке, счётчики чисел, круговой индикатор влажности, стрелка барометра, вращающийся ветряк (скорость зависит от ветра), прорисовка графика, FLIP-анимация сортировки карточек, всплывающие уведомления и окна подтверждения.

## Структура проекта

```
app.py               — сервер Flask: маршруты сайта, API, панель администратора
database.py          — схема БД, начальные и демо-данные
weather_service.py   — загрузка погоды из Open-Meteo
templates/           — HTML-шаблоны (Jinja2), admin/ — шаблоны админки
static/css/style.css — стили и CSS-анимации
static/js/           — main.js (интерфейс), sky.js (анимация неба), chart.js (график)
vendor/              — Flask и зависимости (для запуска без интернета)
run.bat              — запуск в Windows
```
